# Portfolio Website: JoseMata.dev

**JoseMata.dev** is a responsive personal portfolio website designed to showcase my professional projects, resume, and contact information. The site is built to be clean, fast, and user-friendly, while remaining fully expandable as I add new projects, demo videos, and features. It serves as a central hub for anyone wanting to explore my work and technical skills.  

## Features
- **Project Showcase:** Each project includes a detailed description, tech stack, and links to live demos, sample files, or GitHub repositories.  
- **Resume Access:** Visitors can view or download my latest resume directly from the website.  
- **Contact Information:** A simple, intuitive section allows visitors to reach out via email or social media links.  
- **Responsive Design:** Optimized for desktops, tablets, and mobile devices for a consistent experience across platforms.  

## Technology Stack
- **Backend:** Python Flask for routing, dynamic content, and backend logic.  
- **Frontend/UI:** HTML5, CSS, and Bootstrap for a clean, responsive, and modern design.  
- **Deployment & Containerization:** Docker for consistent environment setup; deployed on Amazon Web Services Elastic Beanstalk for scalability and reliability.  
- **Ongoing Development:** Regular updates improve performance, scalability, and user experience, while adding new project demos and features.  

## Purpose
This website demonstrates my ability to build full-stack applications, manage cloud deployments, and design professional, responsive web interfaces. It serves both as a portfolio for potential employers and a sandbox for experimenting with new web technologies.
